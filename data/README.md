
Data

Esta carpeta contiene los datos utilizados en el análisis de accidentes automovilísticos en Estados Unidos.

Archivos
US_Accidents_March23.csv

Dataset original utilizado como fuente principal del análisis.

Debido a su tamaño (aproximadamente 2.9 GB), el archivo no se incluye directamente en este repositorio, ya que GitHub limita el tamaño de los archivos individuales.

US_Accidents_clean.parquet

Versión procesada y limpia de los datos utilizada durante el análisis.

Este archivo se genera como parte del proceso de preparación de datos y tampoco se incluye en el repositorio debido a su tamaño.

Flujo de datos

El proceso seguido en el proyecto es

Dataset original → Limpieza y transformación (Jupyter notebook) → Dataset procesado → Análisis → Visualización en Power BI

La limpieza y transformación de los datos se encuentra documentada en el notebook principal del proyecto

notebookCar_Accidents.ipynb

Nota sobre los archivos de datos

Los archivos completos no se almacenan en GitHub debido a sus dimensiones. El repositorio contiene el código y la documentación necesarios para comprender y reproducir el proceso de análisis.
